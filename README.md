# TMCV Stock Analysis — Python

Analyses 3 months of NSE stock data for TMCV using Python and Pandas.

## What it does
- Reads historical stock data from NSE
- Cleans and processes the data
- Finds the highest closing price in the period
- Shows the exact date it occurred

## Tools used
- Python 3.12
- Pandas

## How to run
1. Download the repo
2. Run: python TMCV.py
